# Six-state thermodynamic inference

This folder contains the complete minimal workflow used to reproduce the
zero-microstate-entropy inference and Figure S12 for the six-state toy model.

## Contents

- `particle_assignments.pkl`: cooled-state assignments used as input.
- `Thermodynamic_Inference.py`: samples the thermodynamically
  allowed region using the entropy-production equations from the manuscript.
- `Plot_Figure_S12.ipynb`: creates the six-panel figure from the inference
  output.
